# inpit-volunteering

Цель:
Создать платформу для регистрации студентов на волонтерские мероприятия университета.

## Стек
Frontend:
- HTML
- CSS
- JavaScript
  
Backend:
- Node.js
- Express

Database:
- SQLite
  
Роли:
- Student
- Admin

Функционал студента:
- регистрация
- вход
- просмотр мероприятий
- запись на мероприятие

Функционал администратора:
- создание мероприятий
- редактирование мероприятий
- просмотр участников

### Реализовано

- Регистрация пользователей - frontend + backend
- Авторизация пользователей - frontend + backend
- Сессии пользователей - backend
- Разграничение ролей Student / Admin - backend
- Создание мероприятий администратором - frontend + backend + SQLite

### В процессе

- Отображение авторизованного пользователя в интерфейсе
- Полноценный интерфейс профиля
- Получение и отображение мероприятий из базы данных
- Редактирование и удаление мероприятий
- Запись студентов на мероприятия
- Просмотр участников мероприятия
