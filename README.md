# inpit-volunteering

Цель:
Создать платформу для регистрации студентов на волонтерские мероприятия университета.

Роли:
- Student
- Admin

Функционал студента:
- регистрация
- вход
- просмотр мероприятий
- запись на мероприятие

Функционал администратора:
- создание мероприятий
- редактирование мероприятий
- просмотр участников
